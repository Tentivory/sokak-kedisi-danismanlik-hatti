# Sokak Kedisi Danışmanlık Hattı

Bu repository, dünyanın en ciddi ve aynı zamanda en saçma sokak kedisi danışmanlık hizmetini sunar.

## Ne İşe Yarar?

Hiçbir şeye. Ama gerçekten çalışır. Sorununuzu yazarsınız, kedi size derin, felsefi ve tamamen işe yaramaz bir tavsiye verir.

Örnek:
```
Sorunun nedir kısaca? işim bitmiyor
Sokak Kedisi: Kutu bul. Kutuya gir. Sorun çözülür. Senin sorun: 'işim bitmiyor' tamamen anlamsız ama işte böyle.
```

## Nasıl Kullanılır?

```bash
python3 kedidanisman.py
```

Python 3 yeter. Bağımlılık yok. Kediler bedava.

## Neden Bu Repo?

Çünkü sokak kedileri her şeyi bilir. Ve çünkü hayat zaten saçma.

## Özellikler

- Rastgele kedi tavsiyeleri
- Türkçe felsefe
- Hiçbir şey çözmez
- %100 organik sokak kedisi enerjisi
